## Introduction

This quickstart guide will show you how to extract structured data from any website using the Wetrocloud API. In just a few minutes, you'll be able to:

- Extract data from any URL
- Define your own JSON schema for structured output
- Use AI-powered prompts to specify what data to extract

**Prerequisites:**
- An API key from the [Wetrocloud Console](https://console.wetrocloud.com)

## Your First Data Extraction

Let's extract billionaire names and net worth from a news article.

<Steps>
  <Step title="Install SDK (Optional)">
    While you can use the API directly with cURL, our SDKs make integration easier.
    <CodeGroup>
  ```bash Python
  pip install wetro
  ```
  ```bash JavaScript
  npm install wetro-sdk
  ```
  ```bash cURL
  # No installation needed for cURL
  curl --version
  ```
    </CodeGroup>
  </Step>

  <Step title="Make Your First Request">
    Extract structured data from a website by providing a link, prompt, and JSON schema.

    <CodeGroup>
```bash cURL
curl --location 'https://api.wetrocloud.com/v1/extract/' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Token <api_key>' \
  --data '{
    "link": "https://theweek.com/news/people/954994/billionaires-richest-person-in-the-world",
    "prompt": "Extract the names and networth of Billionares in the article",
    "json_schema": [
      {"name": "string"},
      {"networth": "number"}
    ],
    "delay": 2
  }'
```

```python Python
from wetro import Wetrocloud

# Initialize the client
client = Wetrocloud(api_key="your_api_key")

# Extract data from a website
response = client.extract(
    link="https://theweek.com/news/people/954994/billionaires-richest-person-in-the-world",
    prompt="Extract the names and networth of Billionares in the article",
    json_schema=[
        {"name": "string"},
        {"networth": "number"}
    ],
    delay=2
)

print(response)
```

```javascript JavaScript
import Wetrocloud from "wetro-sdk";

// Initialize the client
const client = new Wetrocloud({
  apiKey: "your_api_key"
});

// Extract data from a website
const response = await client.extract({
  link: "https://theweek.com/news/people/954994/billionaires-richest-person-in-the-world",
  prompt: "Extract the names and networth of Billionares in the article",
  json_schema: [
    { name: "string" },
    { networth: "number" }
  ],
  delay: 2
});

console.log(response);
```
    </CodeGroup>
  </Step>

  <Step title="Try Different Schemas">
    You can customize the JSON schema to extract different types of data. Here are some examples:

    **Extract product information:**
    <CodeGroup>
```bash cURL
curl --location 'https://api.wetrocloud.com/v1/extract/' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Token <api_key>' \
  --data '{
    "link": "https://example.com/products",
    "prompt": "Extract all product details",
    "json_schema": [
      {"product_name": "string"},
      {"price": "number"},
      {"rating": "number"}
    ]
  }'
```

```python Python
response = client.extract(
    link="https://example.com/products",
    prompt="Extract all product details",
    json_schema=[
        {"product_name": "string"},
        {"price": "number"},
        {"rating": "number"}
    ]
)
```

```javascript JavaScript
const response = await client.extract({
  link: "https://example.com/products",
  prompt: "Extract all product details",
  json_schema: [
    { product_name: "string" },
    { price: "number" },
    { rating: "number" }
  ]
});
```
